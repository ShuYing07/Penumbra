# 疏影·知微 UI 设计指南

> 本文档定义「疏影·知微」的设计系统与配色规范，供开发者与贡献者参考。
> 设计语言参考：OpenBB Workspace / FreqUI Ultimate / Stonks / OpenTerminal / go-stock / Vibe-Research。

## 1. 设计原则

| 原则 | 说明 |
|---|---|
| 首屏即价值 | 用户打开程序 3 秒内看到有意义内容（示例分析/市场概览），而非空白或加载中 |
| 对话优先 | 首页即对话输入框 + 快捷入口卡片，比按钮式导航更低门槛 |
| 键盘驱动 | Ctrl+K 全局命令面板是标配；快捷键覆盖高频操作 |
| 玻璃拟态 + 暗色 | 半透明卡片 + 细边框 + 大圆角，兼顾专业感与视觉吸引力 |
| Widget 化工作区 | 信息面板可停靠/浮动/关闭，布局保存恢复，建立"这是我的工作台"的归属感 |
| 每一步都有反馈 | 加载、分析、保存均有明确视觉反馈（时间线打勾/状态栏/空状态引导） |

## 2. 信息架构（任务导向分组导航）

左侧导航按任务阶段分组：

| 分组 | 功能 | 设计意图 |
|---|---|---|
| 发现 | 对话分析、市场概览、股票大全 | 找到值得研究的标的 |
| 研究 | 自选股、分析、K线图、多空辩论、产业图谱 | 深入理解一只股票 |
| 验证 | 模拟盘、回测、组合回测、参数寻优、信号回放 | 验证自己的判断 |
| 积累 | 学习库、决策记录、分析日志、合规审计、Swarm估值、合规监控 | 沉淀知识、回顾历史 |
| 系统 | 协作空间、风控、数据源、隐私与数据 | 系统与治理 |

- 右侧信息面板为 `QDockWidget`（可浮动/关闭），布局经 `saveState()/restoreState()` 保存到 `QSettings("Shuying","ShuyingInsight").value("dock_state")`，下次启动恢复。
- `视图` 菜单提供「显示/隐藏信息面板」「恢复默认布局」。

## 4. 组件规范

| 组件 | 规范 |
|---|---|
| 卡片（QFrame[glass=true]） | 背景 `bg_card`、1px `border_glow` 边框、圆角 16px |
| 按钮 | 圆角 10px；`:checked` 时 `rgba(0,229,255,0.12)` 背景 + accent 左边条 |
| 输入框 | 圆角 10px，`:focus` 边框 accent |
| 分组标题 | 11px 加粗 `text_sub`，位于导航分组上方 |
| 表格 | 背景 `bg_card_solid`、隔行 `bg_hover`、选中 `rgba(0,229,255,0.15)` |
| 图表（PyQtGraph） | 背景 `#0D1117`（暗色）、网格 alpha 0.25、十字光标 + TextItem 图例 |
| 滚动条 | 8px 圆角细滚动条 |

## 5. 交互模式

### 全局快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+K` | 全局命令面板（功能/股票/历史，支持拼音缩写） |
| `Ctrl+1~9` | 切换左侧导航（按分组顺序） |
| `Ctrl+M` | 明暗主题切换 |
| `Ctrl+Shift+A` | 唤起 AI 对话（对话分析页） |
| `Ctrl+Shift+B` | 打开多空辩论 |
| `Ctrl+Shift+R` | 打开回测 |
| `Esc` | 关闭弹窗/命令面板 |

### 全局命令面板

- 输入即过滤（不区分大小写）；
- 支持：功能名（如"回测"）、股票代码/名称/拼音（`600519`/`茅台`/`gzmt`）、最近分析历史；
- 上下键选择、回车执行、Esc 关闭。

### 浮动 AI 按钮

- 界面右下角圆形 `🤖` 按钮；点击切到对话分析页并聚焦输入框；
- 自动感知当前股票：优先读取分析页输入框，其次右侧面板当前标的。

## 6. 状态与反馈

| 场景 | 设计 |
|---|---|
| AI 分析中 | 对话区展示 4 步时间线（识别市场→采集行情→计算指标→生成报告），逐步打勾 |
| 分析完成 | 追加「✅ 本轮分析已保存到本地知识库」 |
| 无数据 | K线图提示"请输入股票代码（如 600519 / AAPL / 0700.HK）"，不显示 0.1~0.9 默认刻度 |
| 表格空 | "暂无数据，点击上方按钮开始分析" |
| 网络失败 | 状态栏红色提示 + 重试按钮 + 自动降级缓存/示例数据（不弹阻塞弹窗） |
