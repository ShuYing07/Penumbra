# 合规设计（COMPLIANCE）

本文说明疏影·知微在 **数据隐私（GDPR/CCPA）**、**金融合规** 与 **企业审计（SOC 2 就绪）** 三方面的设计。

## 一、数据隐私：GDPR / CCPA

### 1.1 数据主体权利（已实现）

| 权利 | GDPR 条款 | 实现 |
|------|----------|------|
| 知情权 | 第 13/14 条 | `PRIVACY.md` 明示全部数据处理范围 |
| 访问权 | 第 15 条 | `core/privacy_compliance.py::export_user_data()` |
| 数据可携权 | 第 20 条 | 一键导出 JSON（含数据源清单） |
| 被遗忘权（删除权） | 第 17 条 | `delete_user_data()` 事务性删除 + 审计留痕 |
| 拒绝出售权 | CCPA §1798.120 | 无收集/无出售/无共享，天然满足 |
| 同意管理 | GDPR 第 7 条 | `consent_records` 表记录版本+时间+动作 |

### 1.2 隐私设计（Privacy by Design）
- 数据**本地优先**：SQLite 在用户机器，无账号体系、无遥测；
- **最小化**：仅存储用户主动产生的分析/决策数据；
- **加密密钥本地化**：API Key 只存本机 `.env`；
- **跨境传输**：仅当用户主动配置海外 AI API 时，发送指定分析文本。

## 二、金融合规（荐股软件红线）

依据中国证监会《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》：

### 2.1 程序定位
- **数据展示与历史统计工具**，不做投资分析意见、不预测价格走势、不给买卖时机建议；
- 所有 AI 输出经 `core/compliance.py` 过滤，命中"买入/目标价/推荐"等词自动替换；
- 固定免责声明常驻界面底部与输出尾部。

### 2.2 企业合规规则引擎（已实现）
`core/compliance_checker.py`：
- 禁投清单（个股/行业/ST）；
- 单标的仓位上限、单行业暴露上限；
- 违规自动标记 + 审计联动（`mark_violation`）。

### 2.3 审计追踪（已实现）
`core/audit_logger.py`：登录/分析/回测/导出/删除/权限变更全部记录，
追加式不可篡改，支持 CSV 导出 —— 满足金融机构监管审查的"决策链路可追溯"。

## 三、企业安全就绪（SOC 2 / ISO 27001 方向）

| 信任服务标准 | 当前状态 | 说明 |
|-------------|---------|------|
| 安全性 | 部分就绪 | 本地存储 + RBAC + JWT（标准库 HMAC）；生产建议换密钥库 |
| 可用性 | 就绪 | 数据本地冗余（SQLite WAL）；企业版编排含健康检查 |
| 保密性 | 部分就绪 | 传输加密依赖用户所选 AI API；本地数据无加密（可选加装） |
| 隐私性 | 就绪 | 见第一部分 |
| 处理完整性 | 就绪 | 全链路审计日志 |

> 完整 SOC 2 / ISO 27001 认证需第三方审计，本仓库提供"合规就绪"架构，认证作为企业版路线图阶段四目标。
