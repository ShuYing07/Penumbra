# Token 节省与缓存优化策略

## 固定系统提示词（触发前缀缓存）
- System Prompt 每次请求完全一致，不要在前面加动态内容
- 不变内容（角色设定、项目规则、代码风格）放最前面
- 动态内容（用户问题、文件内容）放最后

## 追加式前缀
- 项目规则 → 代码规范 → 当前任务 → 用户输入
- 不要在每次对话开头重复说明项目背景（已在 System Prompt 里）

## 最小化工具调用
- 不需要读文件时不要让 Cline 读
- 一次让 Cline 看完需要的文件，不要反复打开
- 禁用不必要的工具（如终端命令）在不需要时

## DeepSeek 缓存
- 前缀缓存命中后成本约为未命中的 1/50
- 缓存有效期约 24 小时
- 尽量在缓存有效期内连续工作，不要长时间中断

## 时间策略
- 工作日 9:00-12:00、14:00-18:00 是高峰，价格约空闲时段2倍
- 尽量把大量编码任务安排在晚间或周末
