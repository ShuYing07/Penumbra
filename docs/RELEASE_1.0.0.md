## 🎯 核心升级：AI 分析升级为多智能体投研管线

1.0.0 最根本的变化：AI 不再只是基于上下文的文本问答，而是运行在一条**可观测、可追溯的多智能体管线**上。你说「帮我分析茅台最近的技术面和新闻」，程序会自动编排：采集行情 → 计算 RSI/MACD/多因子 → 检索新闻 → 情感分析 → 技术/基本面/新闻/情绪四分析师并行研判 → 多空辩论 → 交易员与风控独立审查 → 首席分析师汇总报告。每一步都通过 Execution Console 可视化、可干预。

参考 TradingAgents（106K Star）的四层投研架构，内部部署 **7 位专业分析师**：

| 角色 | 职责 |
|---|---|
| 技术分析师 | K线形态、RSI/MACD/布林带、支撑阻力位识别 |
| 基本面分析师 | 财务健康度、估值指标、同行对比 |
| 新闻分析师 | 实时新闻检索、事件影响评估 |
| 情绪分析师 | 社交媒体情绪、市场热度 |
| 宏观分析师 | 利率、通胀、政策影响 |
| 风险评估师 | 波动率、VaR、压力测试 |
| 深度研究员 | 跨维度综合推理、根因分析 |

分析师分并行执行组运行：数据组（技术/基本面/新闻/情绪）并行，综合组（宏观/风险/深度研究）随后并行。首席分析师汇总意见，风控团队独立审查（可否决/降级），投资组合经理批准/拒绝交易提案。多空辩论支持 **premium 模型增强**（Cohere/通义），输出经质量门控。

## 📊 数据层：实时行情、质量校验与多模态解析

- **实时流管道**：Kafka 主题总线（news.raw / news.processed / market.tick / filings.new），双模运行——检测到 broker 走真实 Kafka，否则自动降级内存总线，UI「实时流」面板展示速率/延迟/积压。
- **实时行情接入**：WebSocket 行情客户端（自动重连：指数退避 1s→2s→4s→8s…最大 30s；心跳保活；预留 QOS / Longbridge 等多源接入）。数据源优先级：**WebSocket 实时流 → AKShare 轮询 → 缓存兜底**。
- **数据质量校验**：自动检测缺失值、异常值（单日波动>50%）、时间连续性，输出质量评分；不合格数据自动切换备源，分析报告标注数据来源与获取时间。
- **多模态解析**：支持 PDF 财报、图表截图、财报电话会议录音三类输入——视觉 LLM 解析图表与 PDF，faster-whisper 转录音频并提取管理层语气（后端未安装时诚实降级，绝不假装解析成功）。

## 🛡️ 回测严谨性：前视偏差检测与审计

参考 quant-backtest-guard（回测照妖镜），实现 **8 条分级审计规则**：

| 规则 | 级别 |
|---|---|
| 前视偏差 / 时间对齐 | critical |
| 过拟合 / 成本忽视 / 数据窥探 | high |
| 多重检验 / 幸存者偏差 / 流动性假设 | info |

回测页面内置「策略审计」页签，输出结构化体检报告；新增 **CI 审计流水线**（`.github/workflows/audit.yml`）：每次代码推送自动运行全量测试 + 回测审计冒烟，阻止严重偏差进入实盘。

## 🕸️ 金融事件知识图谱

构建 **实体-事件-风险三层事件图谱**（本地 SQLite 动态构建，随新闻与公告持续生长）。从新闻提取事件作为锚点（业绩预增、股东减持、政策补贴…），链接到公司实体并传导至风险层。支持事件传导链查询——「政策补贴 → 新能源车销量 → 电池厂商营收」；分析时自动注入图谱上下文（PIT 纪律：回放模式不注入，避免未来事件泄漏）。

## 🎨 UI 交互：专业金融终端体验

- **布局**：图表居中、工具左侧、上下文右侧；暗色主题（#0A0C10）与玻璃拟态浮层。
- **专业图表**：滚轮缩放、拖拽平移、十字光标 tooltip；绘图工具栏含趋势线、斐波那契、**Gann 角度线、Pitchfork、谐波形态、艾略特波浪**。
- **历史 Tick 级回放**：回放引擎（多引擎可选、步进控制），策略验证与教学演示。
- **全局命令面板（Ctrl+K）**：一键搜索股票、功能、历史记录，专业用户手不离键盘。
- **意图驱动导航**：左侧导航重构为「早点听（信息解读）」「特别提醒（信号盯盘）」「任务助手（执行动作）」三大工作区。
- **浮动 AI 助手**：右下角半透明图标，自动感知当前股票与页面内容，随时提问、解释辩论、保存笔记。

## ⚖️ 合规治理：AI-vs-AI 校验机制

实现 **AI 评审员**（AI-vs-AI 合规校验）：前台模型生成分析后，由独立评审 LLM 逐项断言筛查（荐股建议 / 目标价 / 收益承诺 / 数据来源 / 幻觉风险），命中越界即拦截并提示；LLM 不可用时自动降级规则兜底（敏感词表 + 免责声明）。所有输出经过合规过滤。新增**哈希链审计日志**（sha256 链式链接、仅追加 WORM 兼容），每次 AI 分析/评审记录可逐条校验、可导出 CSV/JSON 供外部验证。

## 🏗️ 工程架构：插件化与性能优化

- **插件系统**：PluginBase 抽象基类 + PluginManager 加载器（扫描 plugins/ → 校验 manifest 权限 → 加载 → 注册 UI/工具 → 卸载），支持 zip 安装。已内置情感分析、回测策略、导出格式三个示例插件。
- **启动优化**：延迟加载非核心模块（回测/财报/组合优化等），板块热力图异步取数，分析页（langgraph）懒加载。**首屏启动从 ≈10s 降至 ≈2.7s（提速 3.6 倍）**。
- **打包瘦身**：排除大模型文件与未使用依赖，exe 体积 **45MB**（远低于 300MB 上限）。
- **自动更新检查**：启动后后台对比 GitHub Releases，有新版本提示用户（不自动下载）。
