疏影·知微 - AI 金融数据分析终端
=====================================

## 🎯 项目简介
**疏影·知微** 是一个本地优先的开源 AI 金融数据分析终端，集成多智能体投研团队、严格回测纪律、前沿模型路由和合规沙箱功能，仅供研究学习，不构成投资建议。

## 📋 系统要求
- Windows 10/11 64位
- 内存：8GB+（推荐16GB）
- 磁盘空间：2GB+
- .NET Framework 4.8
- Visual C++ Redistributable 2019

## 🚀 快速启动

### 方法一：桌面快捷方式（推荐）
1. 打开 `D:\StockAIPredictor\dist\疏影知微\` 文件夹
2. 右键点击 `疏影知微.exe`
3. 选择「发送到」→「桌面快捷方式」
4. 双击桌面上的「疏影知微」快捷方式启动

### 方法二：直接运行
1. 进入 `D:\StockAIPredictor\dist\疏影知微\` 目录
2. 双击 `疏影知微.exe`
3. 或运行 `启动.bat`

### 方法三：命令行启动
```cmd
cd D:\StockAIPredictor\dist\疏影知微\
疏影知微.exe
```

## 🔧 配置说明

### 首次运行配置
1. 程序会自动创建 `data` 目录用于存储数据
2. 如果没有 `.env` 文件，会自动创建默认配置
3. 编辑 `.env` 文件，填入您的 API Key：
   ```
   DEEPSEEK_API_KEY=your_api_key_here
   ```

### API Key 配置
支持多种 AI 服务提供商：
- **DeepSeek**（推荐）：金融专用模型效果最佳
- **OpenRouter**：多模型路由
- **OpenAI**：GPT 系列
- **本地模型**：Ollama + Ling-3.0-flash-fin

## 🔍 故障排除

### 程序无法启动
1. **检查依赖**：
   - 确保 .NET Framework 4.8 已安装
   - 确保 Visual C++ Redistributable 2019 已安装
2. **检查权限**：
   - 右键程序 → 属性 → 解除锁定
   - 关闭 Windows Defender 实时保护
3. **检查内存**：
   - 关闭其他大内存程序
   - 重启电脑释放内存

### AI 分析失败
1. **检查 API Key**：确认 `.env` 文件中的 Key 正确
2. **检查网络**：确保能访问 AI 服务提供商
3. **检查配额**：确认 API 配额未用完

### 图表显示异常
1. **检查显卡驱动**：更新显卡驱动到最新版本
2. **检查 DirectX**：确保 DirectX 12 已安装
3. **降低分辨率**：临时降低显示分辨率测试

### 数据获取失败
1. **检查网络**：确保能访问金融数据源
2. **使用代理**：如果在国内，配置代理
3. **切换数据源**：在设置中切换不同的数据源
