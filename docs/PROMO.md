## 二、GitHub README 开头简介（直接可用）
StockAIPredictor 是一个在你自己电脑上运行的金融数据分析工具：输入股票代码，它拉行情、算技术指标、聚合新闻情感，用大模型做客观数据描述。
- 🔒 **本地优先**：数据不出本机，不注册不追踪，开源 MIT；
- 🗣️ **对话式**：输入"茅台"即可，三栏联动（自选股 / 对话 / K线）；
- 💰 **免费可扩展**：默认接通义千问/DeepSeek，也能切本地 Ollama 完全离线；
- ⚠️ 纯研究工具，不荐股、不碰交易。
