## 二、TradingAgents（主参考，104k★）
**架构（LangGraph 状态图，模拟真实交易公司分工）：**
```
分析师团队 → 研究员团队（多头 vs 空头辩论）→ 交易员 → 风险管理团队 → 组合经理（最终拍板）
├ 基本面分析师（财报/估值）
├ 情绪分析师（新闻标题、StockTwits、Reddit 舆情）
├ 新闻分析师（全球新闻/宏观指标）
└ 技术分析师（MACD、RSI 等技术指标）
```
**值得直接复用的设计：**
1. **角色分工 + 多空对抗辩论**：比"单个 LLM 给结论"质量高、偏差小——这就是"先进算法整合推演"的落地形态。
2. **决策日志记忆（trading_memory.md）**：每次决策追加落盘；下次分析同标的时，拉取已实现收益（含相对 SPY 的超额收益），自动写一段反思，连同历史决策注入组合经理提示词——**这就是"自我学习"的可复用模式，且实现成本低（Markdown/SQLite 即可）**。
3. **检查点续跑（checkpoint resume）**：LangGraph 每个节点后存 SQLite，中断后从最后成功步骤恢复；分析流程长（多个 LLM 调用），这点很实用。
4. **结构化输出**：研究员/交易员/组合经理等节点用结构化（JSON schema）输出，决策信号明确。
5. **数据覆盖面**：用 Yahoo Finance 一套代码支持全球市场——美股 AAPL、港股 0700.HK、日股 7203.T、A股 600519.SS/000001.SZ、加密 BTC-USD。与我们"A股+美股+加密"需求吻合（A股深度数据仍用 akshare 补强）。
6. **LLM 多厂商可插拔**：OpenAI/Google/Anthropic/DeepSeek/Qwen/GLM/Ollama 及任意 OpenAI 兼容端点；DeepSeek 是官方支持项之一。
7. **配置化**：`DEFAULT_CONFIG` 字典控制模型选择（deep_think_llm / quick_think_llm 分级）、辩论轮数、temperature。

**它踩过并已修复的坑（直接吸取，不重踩）：**
- v0.3.1（2026-07）：**Alpha Vantage 前视偏差（look-ahead）过滤**——宏观/情绪数据用到了"当时不可能知道"的未来信息。
- v0.4.0（2026-08）：**FRED 宏观、社交情绪、决策记忆全链路 point-in-time 修复**；"交易员价格锚定（Trader price grounding）"防止 LLM 瞎编价格。
- v0.2.4（2026-04）：**Windows UTF-8 编码修复**（中文 Windows 跑 LLM 框架的经典坑）；LangGraph checkpoint 续跑；持久化决策日志；DeepSeek/Qwen/GLM 支持；Docker。
- v0.2.2：**代理（proxy）支持**——国内网络调境外 API/数据源需要。
- 复现性说明：LLM 输出天然非确定（尤其思考模式模型），同票同日两次结果可能不同；可降 temperature 提升一致性。新闻数据随时间变化，历史回测日期只能固定价格/指标窗口，社交/新闻反映的是"现在"。

## 三、ai-hedge-fund（主参考，63k★，MIT）
**演进方向**：已重构为"持久化、常开的 AI 对冲基金"——**基金（fund）是一等实体**，可回测、可模拟盘（paper-trade）、可选接实盘；投资人智能体被改造成可插拔、可回测的"alpha 模型"。
**模块化目录（值得借鉴的切分）：**
`backtesting/ brokers/ data/ event_study/ features/ fund/ llm/ pipeline/ portfolio/ risk/ signals/ strategies/ tui/ validation/`
**值得复用：**
1. **mandate（授权书）概念**：策略/人员/风控/资金/调仓周期与标的解耦，回测/模拟/实盘共用同一套决策逻辑。
2. **alpha 模型可插拔 + 可回测**：每个信号源（技术/基本面/情绪…）是独立模块，输出标准化信号，便于组合与验证。
3. **回测与模拟盘作为一等公民**：不是先做功能再补回测，而是一开始就让决策流可回放。
4. **LLM 密钥按需询问、落 `~/.hedge-fund/.env`**；支持 DeepSeek 等 6 家。
5. 交互式 TUI 思路（我们用 PyQt6 替代）。
**不照搬：**
- 数据依赖 Financial Datasets API（付费 key，美股为主）→ 我们用免费的 akshare/yfinance/CoinGecko 替代。

## 四、其他项目的取舍
- **qlib（微软，48.5k）**：因子工程+ML 训练的重型平台，数据格式自有、学习曲线陡。MVP 不用；后期若加"自训练预测模型（LSTM/梯度提升）"可参考其因子/回测范式。
- **OpenBB（73k）**：数据聚合能力强，但许可证为 NOASSERTION（AGPL 类），打包进闭源个人 exe 有顾虑；只借鉴其"多数据源统一接口"的思路，不引入依赖。
- **FinGPT / FinRL**：金融大模型微调、强化学习——需要算力和大量数据，属于远期增强，MVP 不碰（LLM 推理本身已能提供"分析整合"能力）。
- **yfinance（25.2k）**：直接依赖。注意它历史上频繁因 Yahoo 接口变动而 break，必须加缓存+适配器隔离。
- **akshare（22.5k）**：直接依赖。A股行情/财务/龙虎榜/北向/财联社电报等中文数据最全，但本质是爬虫封装，接口会随东财/新浪页面变动而失效——同样要适配器隔离+优雅降级。

## 五、复用 / 避坑清单（一页速查）
**直接复用：**
- 多智能体分工（技术/基本面/新闻/情绪分析师 → 多空辩论 → 交易员 → 风控 → 最终决策），LangGraph 编排。
- 决策日志 + 事后收益反思注入（自我学习闭环）。
- 检查点续跑（SQLite，长流程容错）。
- Pydantic 结构化输出 + 交易员价格锚定（防幻觉）。
- point-in-time 数据纪律（回测只用当时可得数据）。
- 双模型分级：复杂推理用强模型，摘要/分类用便宜快模型（成本控制）。
- 配置化 LLM 提供商（预留 OpenAI 兼容端点，日后可换）。

**必须避开：**
- 前视偏差（回测/模拟用了未来数据）——TradingAgents 两次大版本才修干净，我们第一行回测代码就要守纪律。
- LLM 直接报数字（价格/指标必须程序算好喂给它，它只做解读与决策）。
- 数据源裸调（yfinance/akshare 都会变/会限流）——统一走 data 适配器 + SQLite 缓存。
- 中文 Windows 编码坑——所有文件读写显式 UTF-8。
- 一次 LLM 调用跑完全流程——拆节点、可重试、可续跑、可观测进度。
- 无免责声明——所有报告页脚固定"仅供学习研究，不构成投资建议"。
