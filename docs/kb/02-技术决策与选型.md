# 02 · 技术决策与选型（2026-09-10 锁定）

## 一、用户已拍板的四项决策
1. **市场范围**：A股 + 美股/港股/全球 + 加密货币（BTC/ETH 等），全市场覆盖。
2. **AI 方案**：DeepSeek 云端为主（OpenAI 兼容接口，国内直连、成本极低）；架构预留本地 Ollama/其他 OpenAI 兼容端点。
3. **界面形态**：PyQt6 原生桌面窗口，最终打包为双击即用的 exe。
4. **程序定位**：学习研究 + 模拟盘（paper trading）；**不接券商实盘、不自动下单**；所有输出带风险提示。

## 五、成本与性能估算
- DeepSeek flash 定价（2026-09 核实）：输入约 1~2 元/百万 tokens、输出 4~8 元/百万（高峰），空闲时段半价；1M 上下文。
- 单标的一次完整分析（4 分析师 + 2 轮辩论 + 交易员 + 风控）约 3~6 万 tokens → **约 0.1~0.3 元人民币**；每天分析 10 个标的月成本 < 100 元。
- 省钱手段：行情/新闻全走本地缓存不重复喂；摘要/分类用 flash；仅最终推演可切 v4-pro；利用缓存价。

## 六、本地离线引擎 + 蒸馏自学习（2026-09-11 增补）

### 6.1 决策：Ollama + Qwen2.5-7B-Instruct Q4_K_M
- **本机基线实测**：RTX 5060 Laptop 8GB / i9-14900HX / 16GB。7B-Q4 模型 4.7GB，8 节点全链路 **26~34 秒、约 1 万 tokens、零费用**（模型驻留显存后单节点 2~5 秒）。
- 为什么是 Ollama：自带打包 CUDA/CPU 运行库（含 Blackwell 支持，0.34 实测可用），Windows 一键安装，暴露 OpenAI 兼容端点 `/v1`，LLMRunner 零成本切换；模型管理/并发/显存调度它全包。
- 为什么是 Qwen2.5：中文金融语料充分、JSON 指令遵循在同尺寸中最好；备选 3B（约 2GB，低配/纯 CPU）。
- **不打包进 exe**：Ollama（700MB+）和模型（4.7GB）均运行时检测引导下载，exe 体积不膨胀；这是"独立运行 exe + 本地 AI"的合理边界。
- 未选 llama-cpp-python 直连：需自行编译/管理 CUDA 运行库与模型文件，Ollama 已把这些脏活做完。
- 未选内置 LoRA 训练：torch 依赖数 GB，与 exe 分发冲突；训练是低频离线任务，独立 GPU 环境做（见 6.3）。

### 6.2 三后端路由（core/llm.py）
`STOCKAI_LLM_BACKEND=deepseek|local|auto`（UI 分析页下拉，CLI `--backend`）：
- deepseek：云端默认，质量最高；
- local：纯本地，零费用零联网（采集行情仍联网，分析推理离线）；
- auto：先云端，遇 **402/连接异常/超时**自动切本地，一次分析内切后保持（闩锁不抖动）。
- 本地调用 token 照记账、成本恒 0；访问 127.0.0.1 的 requests/httpx 全部 trust_env=False 绕代理（坑14）。

### 6.3 蒸馏自学习闭环（core/training/distill.py，data/distill/）
1. **SFT 教师语料**（sft.jsonl）：云端成功推理自动记 source=teacher，本地成功记 source=student；mock/失败不记（垃圾不进库）。
2. **决策偏好标注**（preferences.jsonl）：决策满 10 交易日反思后自动打 good/bad/neutral + 实际收益%（无前视偏差）。
3. **导出训练集**：`scripts/export_distill.py` 或学习库页按钮 → LLaMA-Factory alpaca 格式 + 偏好标注 + 训练说明 README；未来流程：LoRA SFT（qwen2.5-7b，≥12GB 显存）→ bad 样本用教师重生成 chosen 配 DPO 对 → `ollama create` 导入 → `.env` 设 STOCKAI_LOCAL_MODEL 替换学生模型。
4. "在线就变强"的现实组合（不靠真训练也逐日增强）：云端教师语料持续积累 + RAG 摄入新闻/报告/反思 + 到期反思注入后续 prompt + 相似历史形态检索，四者已闭环。

### 6.4 本地模型的契约加固（schemas.py）
7B 输出格式漂移频繁，所有字段 pydantic 校验**前**归一化：立场/动作近义词、中文置信度、"25%"字符串、"是"布尔、null 文本、dict 形列表条目、概率越界 clamp（坑16）。原则：**容错放契约层，节点代码和 prompt 不堆补丁**。

## 八、策略回测引擎（2026-09-11 八期，core/quant/backtest.py）

### 8.1 决策：自研轻量引擎，不引 backtrader/vectorbt
规则策略+日线+单标的，pandas 逐日循环即可严格控制成交价与费用；引回测框架会增加打包体积和学习成本，且 t+1 成交/整手/A股费率仍需定制。零新增依赖，纯计算无 IO 无 LLM，秒级可重复。

### 8.2 防作弊纪律（最高优先级）
- 信号在 t 收盘用截至 t 数据生成，**t+1 开盘成交**（滑点后价），末根 K 线信号不挂单；单测 `test_no_lookahead_fill_at_next_open` 锁死；
- 指标 NaN 预热窗不出信号；<30 根日线直接 ValueError，不静默出空结果；
- 真实费率：CN 佣金万2.5最低5元（双边）+印花税千0.5（卖出）+过户费十万1（双边）；US 佣金万3；CRYPTO 千1；滑点默认 5bp（CRYPTO 10bp）；
- 单标的只做多、all-in/all-out、仓位%可配；CN 整手100，US 4 位小数，CRYPTO 6 位；买入统一走 `_size_position()` 在含滑点成交价上测算并循环缩量到含费金额≤现金（坑24）。

### 8.3 策略注册表与指标
- 策略 key→信号函数（输出 1/-1/0 Series，持仓状态由引擎管，重复信号忽略）：rsi_reversion / ma_cross / macd_cross / buy_hold（首日开盘满仓，引擎特判）；STRATEGY_META 登记中文标签+参数规格供 CLI/UI 自动生成，加策略只加一个函数；
- 指标：总收益、年化（252 日）、基准（买入持有解析曲线，碎股不收费率约束）、超额、最大回撤、夏普（rf=0 日收益年化）、胜率/盈亏比/平均持仓（按完整买卖回合）、总费用。

### 8.4 入口与留痕
- CLI：scripts/run_backtest.py TICKER --strategy/--capital/--position/--start/--end + 各策略参数，结果 JSON（指标+流水+权益曲线）落 data/backtests/；
- GUI：第 6 标签"回测"（backtest_tab.py），QThread Worker（复用 service.get_daily 缓存优先），指标表+pyqtgraph 策略 vs 基准虚线+成交流水表（买红卖绿），同样落盘留痕；
- spec 无需改（main_window 静态导入 backtest_tab，PyInstaller 自动跟踪）；下次重打 exe 生效。

### 8.5 后续扩展位（不在本期）
AI 信号历史回放（按日重放 8 节点，token 成本高，需批量缓存）、组合级回测、参数网格寻优、Walk-forward（待 ML 因子）、更多策略（KDJ/布林突破）——注册表模式均可低成本加入。
