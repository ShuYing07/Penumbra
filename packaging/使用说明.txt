StockAIPredictor 虚拟股票预测（学习研究版）使用说明
=====================================================

【这是什么】
AI 多智能体股票分析 + 模拟盘程序：联网获取 A股/美股/加密货币行情与资讯，
8 个 AI 智能体（技术面/基本面/新闻面/情绪面分析师 → 多空研究员辩论 →
交易员 → 风控终审）推演后输出中文操作方案，并自动进模拟盘虚拟成交；
决策到期自动复盘、相似历史形态检索、学习资料语义检索。
AI 支持云端 DeepSeek 与本地离线模型两种引擎，可自动切换。

【重要声明】
仅供学习研究，不构成任何投资建议；不接入实盘交易；
历史表现与 AI 推演不预示未来收益，据此操作风险自负。

【快速开始】
1. AI 引擎（分析页"引擎"下拉，三选一）：
   · 云端 DeepSeek：质量最高，需在本目录 .env 填 DEEPSEEK_API_KEY=sk-xxxx，
     单次分析约 0.1~0.3 元；
   · 本地模型（完全离线·免费）：首次点"本地模型…"按钮安装 Ollama 并下载模型
     （Qwen2.5-7B 约 4.7GB，仅一次；8GB 显存流畅，纯 CPU 可选 3B 小模型），
     之后推理不联网、不花一分钱；
   · 自动：优先云端，余额不足/断网时自动切本地，全程不中断。
   未配置任何模型时：勾选"离线演示(MOCK)"仍可体验完整流程（桩数据）。
2. 双击 StockAIPredictor.exe 启动。
3. 在"分析"页输入标的代码开始，例如：
      A股：SH600519（沪）/ SZ000001（深）或 6 位代码
      美股：AAPL、TSLA
      加密货币：BTC-USD、ETH-USD
      港股：0700.HK
4. 行情/新闻采集需要联网（境内直连+境外走系统代理均可）；
   选择"本地模型"后，AI 推理环节完全离线。

【本地模型安装（仅第一次）】
1. 点分析页"本地模型…"→"安装 Ollama（打开官网）"，下载安装一路下一步；
2. 装好后点"重新检测"，状态显示运行中后，点"下载选中模型"等待进度完成
   （4.7GB，国内网络约 20~30 分钟）；
3. 下载完成即可选"本地模型"引擎分析，模型永久保存在本机，可离线反复使用。
   若下载长时间卡在 pulling manifest：通常是 Ollama 后台服务没走代理，
   退出托盘 Ollama → 在代理软件开启状态下重新启动 Ollama 后重试。

【页面说明】
- 分析：跑 8 智能体管线，右侧生成中文报告，可导出 Markdown；
  "决策自动入模拟盘"默认开启；引擎下拉与"本地模型…"管理在同一行。
- K线图：蜡烛图+均线+布林带+成交量，分析完成后自动联动。
- 模拟盘：虚拟资金 100 万起步（可在 .env 用 STOCKAI_PAPER_CAPITAL 修改），
  按决策自动买卖（A股整手、美股/加密碎股），含净值曲线与胜率统计。
- 学习库：报告/新闻/决策反思向量检索 + 相似历史形态检索（含其后真实表现）；
  底部显示"蒸馏语料"积累数（云端教师示范 + 决策对错标签），
  点"导出训练集"可导出 LLaMA-Factory 格式，供未来微调自己的本地模型。
- 决策记录：全部历史决策，满 10 个交易日后自动对照实际涨跌写反思，
  反思会注入后续同类分析，实现自我改进。

【自学习/蒸馏原理（程序如何越用越强）】
1. 每次真实 AI 推理自动存为示范语料（云端=教师，本地=学生）；
2. 决策满 10 交易日自动对照实际涨跌，打"正确/错误"偏好标签；
3. 历史反思、相似形态、学习库资料自动注入后续分析的 prompt；
4. 语料可导出做 LoRA/DPO 微调（需独立 GPU 环境，详见导出目录 README）。

【训练离线模型（教学资源蒸馏）】
想让本地模型更懂金融？可蒸馏网上开放许可的教学资源（维基百科/IMF/证监会投教等）
微调出金融增强模型，全程离线零费用。入口：分析页"本地模型…"→"训练离线模型…"。
四步（后台运行，有进度）：
  1. 资源：勾选内置开放许可源（14 个：维基百科/国际组织/国内投教），点获取；
  2. 蒸馏：本地 7B 教师把教材文本转成 Q&A，自动进蒸馏语料（source=curriculum）；
  3. 训练：QLoRA 4bit 微调（需独立 venv_train，见下）；
  4. 导入：合并 LoRA → 导入 Ollama → 自动设为本地学生模型。
前置（仅首次）：训练依赖独立环境，本程序不内置 torch：
  - 装 Python 3.11（LLaMA-Factory 要求，主 venv 3.14 不兼容）；
  - 跑 powershell -ExecutionPolicy Bypass -File scripts\bootstrap_venv_train.ps1
    一键建 venv_train（装 torch CUDA + llamafactory，约 2.5GB，一次）；
  - 训练需下载 Qwen2.5-7B 基座 ~15GB（自动走 HF 镜像），8GB 显存保守配置可跑通。
命令行等价：python scripts/train_offline.py all（distill→export→train→merge→import）
资源版权：只收 CC-BY-SA/官方投教开放材料，仅本地训练，权重不分发。

【数据都在哪】
全部在本目录 data/ 下（便携式，整个文件夹可拷贝迁移）：
  data/stockai.db      行情/新闻/决策/模拟盘（SQLite）
  data/reports/        每次分析的中文报告
  data/chroma/         学习库向量索引
  data/distill/        蒸馏语料（sft.jsonl/preferences.jsonl/export/）
  data/training/corpus_raw/  教学资源纯文本语料
  data/training/output/      训练产出（LoRA adapter）
  data/logs/           运行日志（排障先看这里）
本地 AI 模型由 Ollama 统一管理（不在本目录，默认在用户目录 .ollama）。

【命令行】
  StockAIPredictor.exe --selftest   打包自检（结果见 data/selftest.log）
  venv 源码方式： python -m app.main
  python run_analysis.py SH600519 --backend local   （本地引擎；deepseek/auto 同理）
  python scripts/export_distill.py                  导出蒸馏训练集
  python scripts/fetch_resources.py --list        列出教学资源源
  python scripts/fetch_resources.py               获取教学资源到语料库
  python scripts/train_offline.py all             离线训练全流程（需 venv_train）

【常见问题】
- 某些数据源偶发连不上：程序会自动切换备源（新浪/腾讯/东财/yfinance/CoinGecko），
  个别失败不影响整体；网络环境剧烈变化时重试即可。
- DeepSeek 余额不足：选"自动"或"本地模型"引擎即可继续；云端充值后自动恢复。
  注意充值要在 platform.deepseek.com（开放平台），与聊天网页版账号不互通。
- 本地引擎提示服务不可用：确认 Ollama 已启动（开始菜单/Ollama 托盘图标）；
  开着代理软件时程序已自动处理本机回环连接，无需额外设置。
- 首次分析较慢（联网采集+多轮推理）；本地模型首次加载需十几秒，之后很快。
