# 疏影·知微 0.8.0 正式发布

发布日期：2026年9月29日
版本号：0.8.0

---

疏影·知微迎来一次深度进化。本次更新聚焦于多智能体投研团队、回测严谨性与数据泄漏防护、组合优化、财务报告深度解析、AI推理过程可观测性五大方向，让程序从“AI分析工具”升级为具备机构级研究纪律的投研平台。

## 🧠 多智能体投研团队全面升级

不再是单一的多空辩论，而是模拟真实投研机构的 7 人分析师团队：

| 角色 | 职责 |
|---|---|
| 技术分析师 | K线形态、RSI/MACD/布林带、支撑阻力位识别 |
| 基本面分析师 | 财务健康度、估值指标、同行对比 |
| 新闻分析师 | 实时新闻检索、事件影响评估 |
| 情绪分析师 | 社交媒体情绪、市场热度 |
| 宏观分析师 | 利率、通胀、政策影响 |
| 风险评估师 | 波动率、VaR、压力测试 |
| 深度研究员 | 跨维度综合推理、根因分析 |

分析师分为并行执行组：数据组（技术/基本面/新闻/情绪）同时运行，综合组（宏观/风险/深度研究）在数据组完成后运行。首席分析师协调各角色，汇总意见，生成最终报告。风控团队独立审查，有权否决或降级结论。

## 🛡️ 回测严谨性与数据泄漏防护

引入 **PIT-Guard（Point-in-Time Guard）** 中间件，在工具调用边界强制执行数据时间戳过滤，防止 AI 读取未来数据。实现机械层与 Agent 层分离：回测引擎只使用确定性规则，LLM 仅用于定性判断，不参与收益计算。回测报告中明确标注“机械层回测”和“Agent层分析”的边界。

支持可插拔协作模式：通过配置切换多 Agent 拓扑（panel / debate / vote），适应不同分析场景。

## 📊 组合优化与风险管理

内置专业组合优化引擎（优先调用 skfolio，未安装时自动使用内置 numpy/scipy 引擎，功能等价可用），支持：

- 均值-风险优化：平衡收益与风险
- 风险平价：等风险贡献配置
- 分层风险平价（HRP）：基于层次聚类的稳健配置
- 最大分散化：最大化组合分散度
- 分布鲁棒 CVaR：极端风险下的稳健优化

UI「组合优化」标签页展示：优化后权重饼图、随机采样组合可行域（有效前沿示意）、风险指标卡、风险贡献分解表与组合回测净值曲线，支持单只股票最大权重约束。

## 📑 财务报告深度解析

新增财报解析引擎：

- 自动提取业绩变动、重大合同、风险提示、管理层讨论（LLM 优先，规则引擎兜底）
- 自动计算可得财务比率（盈利能力、偿债能力、运营效率、成长性；缺失项如实标注，不脑补）
- 构建 5 年 DCF 模型，包含多情景敏感性分析
- 生成“财报摘要卡片”，支持多期对比

「基本面」页升级为财报摘要卡片：一键展示关键信息提取、多期报表对比、财务比率与 DCF 估值结果。

## 🔍 AI 推理过程可观测性

内置 Execution Console 追踪引擎（User / Expert / Dev 三模式），并行瀑布图展示各 Agent 的执行时间与依赖关系。对话页实时时间线让 AI 分析过程全程可见（识别市场 → 采集数据 → 计算指标 → 辩论 → 生成报告）。每次分析的完整事件流持久化到本地 SQLite，支持事后回溯 AI 的完整推理路径。用户不再面对“黑盒等待”。

## 🏗️ 架构与性能

- 启动速度优化：延迟加载非核心模块，后台预热股票索引到内存
- 内存优化：虚拟滚动、分页加载
- 打包瘦身：排除大模型文件与未使用依赖，发行包由 907MB 降至约 396MB（主程序 exe 44.6MB）
- 自动更新检查：启动时对比 GitHub Releases，提示用户下载新版本
