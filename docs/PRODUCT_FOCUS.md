# 产品聚焦：我们只做好一件事

> OpenBB 的教训：**"我们试图成为一切，而大多数公司只是在寻找一个工作流解决方案。"**
> 数据变现虽然诱人，但会改变项目的激励结构，需要慎重。

## 核心工作流（本项目只聚焦这一条）

**「输入一只股票 → 快速理解它的多空逻辑」**

1. 输入代码（支持中文名/拼音缩写/别名，如 `gzmt` → 贵州茅台）；
2. 看 K 线与技术指标（布林带、均线、成交量副图）；
3. 一键 AI 多空辩论（Claim-level 结构化对抗 + 风控 Agent 审查）；
4. 如需，跑一次严格 T+1 回测验证策略；
5. 每次分析留痕，支持复盘。

其他功能（模拟盘、参数寻优、产业图谱、股票大全…）全部服务于这条主线，
不喧宾夺主。

## 取舍原则

| 做 | 不做 |
|---|---|
| 数据本地化、隐私优先 | 云端账号体系、数据变现 |
| 结构化辩论与可审计 | 荐股/买卖建议/价格预测 |
| 开源可审计、社区共建 | 闭源收割 |
| 聚焦工作流做到极致 | 功能堆砌 |

## 为什么用户选我们

如果你在意数据隐私、讨厌广告、想用 AI 辅助研究但不信任云端——
「疏影·知微」就是为你做的：**本地运行、无广告、开源可审计、数据不出本地**。
