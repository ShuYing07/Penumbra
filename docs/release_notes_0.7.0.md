疏影·知微 0.7.0 更新介绍

发布日期：2026年9月28日
版本号：0.7.0
疏影·知微迎来一次全面升级。本次更新聚焦于数据准确性、UI体验、AI记忆、多模型支持四大方向，让程序从“可用”真正走向“好用、爱用、越用越懂你”。

🔧 数据层修复与增强

沪深300历史数据修复：此前K线图加载 000300.SS 仅有1根数据，现已改用 AKShare 专用指数接口 ak.index_zh_a_hist()，可获取完整日线数据（实测6000+行），指数K线不再缺失。

多源数据降级机制：建立 AKShare → Tushare → Baostock 的自动降级链，主源失败时自动切换备源，确保行情数据稳定获取。

创业板指等指数数据接入：修复了399006.SZ等指数数据缺失问题，统一走AKShare指数接口。

🎨 UI 全面重构

玻璃拟态暗色主题：采用 #0A0E17 主背景 + rgba(19,23,34,0.85) 卡片 + 毛玻璃效果，视觉上更专业、更耐看。

任务导向导航：左侧导航按“发现 / 研究 / 验证 / 积累”四阶段分组，用户不再迷失在功能按钮中。

可拖拽 Widget 工作区：K线图、AI摘要、技术指标、新闻面板等模块支持自由拖拽、调整大小，布局自动保存到本地，下次启动恢复原样。

全局命令面板（Ctrl+K） ：一键搜索股票、功能或历史记录，回车直达目标。

浮动 AI 助手：界面右下角新增 AI 按钮，自动感知当前股票与页面内容，可随时提问、解释辩论结果、保存分析到笔记。

对话式首页：打开程序首先看到对话输入框和三个快捷入口卡片，而非密密麻麻的按钮，新用户上手零门槛。

明暗主题一键切换：顶部工具栏新增主题切换按钮，用户可在暗色专业模式与浅色舒适模式间自由选择。

键盘快捷键全覆盖：Ctrl+1~9 切换导航，Ctrl+Shift+A 唤起 AI，Ctrl+Shift+B 打开多空辩论，Esc 关闭弹窗。

🧠 AI 能力升级

持久化记忆与知识库：新增三层记忆架构——短期会话上下文、中期按股票聚合的分析历史、长期用户偏好画像与向量知识库。每次分析自动写入本地知识库，建立“股票 → 行业 → 事件 → 影响链”实体关联。

多模型路由层：不再局限于单一 DeepSeek，现已支持 DeepSeek、通义千问、智谱 GLM、Groq、OpenAI、Gemini、Ollama 本地模型等。系统根据任务复杂度自动路由，主模型不可用时自动降级到备选模型。

多空辩论结构化：从“各说各话”升级为 Claim-level 结构化对抗——多头提出3个核心论点，空头逐一反驳，共2-3轮。不同厂商模型分饰多空，并增加风控 Agent 审查结论。

AI 执行过程可视化：分析过程中用时间线展示步骤（识别市场 → 采集行情 → 计算指标 → 多空辩论 → 生成报告），用户不再“干等”。

分析日志与合规审计：每次 AI 分析的原始输出、过滤后输出、敏感词命中情况自动写入审计日志，决策记录支持筛选、搜索、导出。

📊 图表与交互增强

K线图全面升级：支持滚轮缩放、拖拽平移、十字光标 + 数据 tooltip，可切换日线/周线/月线/分时，叠加布林带、均线、成交量副图。

实时数据刷新：市场概览与自选股每30秒自动刷新，显示最后更新时间，并支持手动刷新。

股票大全性能优化：采用虚拟滚动与分页机制，解决1.8万只股票列表卡顿问题。新增市场筛选（A股/港股/美股）与板块筛选，双击即可加入自选。

板块热力图：市场概览页面新增 Treemap 板块热力图，直观展示各板块涨跌情况。

🚀 用户体验优化

首次启动自动加载示例：程序启动时自动加载贵州茅台（600519）并触发一次完整分析，让用户立即看到价值。

自选股预置：默认包含茅台、宁德时代、沪深300、苹果、腾讯。

空状态引导：所有图表和表格在无数据时显示友好提示与操作按钮，不再是一片空白。

错误降级提示：启动阶段若网络失败，降级显示提示条并提供重试按钮，不再弹窗阻塞。

分享与每日简报：分析完成后可导出 Markdown/PDF、生成分享图片。每日7:30自动生成“今日市场简报”，支持桌面通知与飞书推送。

🏗️ 项目治理与文档

测试脚本统一：分散的 test_*.py 已迁移至 tests/ 目录。

临时文件清理：local_run*.log、out.txt、err.txt 等已加入 .gitignore。

README 视觉化改造：新增项目 Banner、主界面截图、K线图截图、多空辩论截图，顶部放置一键下载链接与“5分钟快速上手”章节。

竞品对比表：清晰展示与同花顺、东方财富、OpenBB 的差异。

Social Preview 与 Topics：GitHub 仓库已设置社交预览图，Topics 添加 finance、trading、ai、quant、pyqt6 等标签。

文档补充：docs/FAQ.md 已扩充，包含沪深300数据源说明、本地模型配置、常见报错处理。
